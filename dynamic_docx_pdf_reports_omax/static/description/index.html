Dynamic Docx Pdf Reports

Overview

This App allows to Download or Attachment Docx/Pdf Report of any Model(standard and custom). User can design docx template and add fields by themselves so, they have option to add whichever fields they want and use default docx features to format the report template.

Features

  • Create new record to add new report for any model.
  • Print or Attach docx or pdf report for any model.
  • User can design template and add fields by them selves.
  • User can print or attach any report which is configured.
  • Manager has access to create new report and can also create/design docx template and use it.
  • Report option available only in form view.

Notes

  • Header and Footer contents will not support fields.
  • Formating in table will not work
  • Merge cell in table will not work
  • Fields Label and value must be in separate cell require(if using inside table) otherwise only value will be printed
  • Image field will work only in table
  • Font name and Font size will be used for the dynamic values of Table
  • If Font name and Font size is not set in docx template configuration then it will be used font and size which is configured in uploaded document(file)
